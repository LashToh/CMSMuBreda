# MU Breda Season 21 CMS

> 🇬🇧 [Read in English](README.md)

CMS moderno de MU Online para **MU Breda Season 21** (servidor oficial / UP).

- **Identidad visual:** Season 21 (colores, tipografías)
- **Stack:** React · Vite · SCSS · Node.js · Express · Microsoft SQL Server

## Primeros pasos

**Requisito:** [Node.js LTS](https://nodejs.org) instalado.

```bash
npm install
npm run dev:all
```

- Frontend: http://localhost:5173
- API: http://localhost:3001

## Módulos del portal

Registro, Login, Rankings (nivel combinado + ML), Noticias, Donar (`/donate`), Descargas, Cuenta y Admin.

Ver [README.md](README.md) para arquitectura, variables de entorno y API.
